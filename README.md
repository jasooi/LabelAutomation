# ASEAN E-commerce Competitor Brands Benchmarking and Trend Analysis
This repo contains the automation scripts for the E-commerce competitor brands benchmarking and trend analysis project. 
This project analyses the market trends of certain product categories in various Southeast Asian countries where my 
previous company sells its products in and informs our D2C e-commerce stores' pricing and marketing strategies via
a dashboard. 

1. Scrape e-commerce listings using a specified list of product keywords and categories from regional e-commerce platforms and save results to csv
2. Use Latest Script.R to process the raw csv and classify listings into internal business units (e.g. YTD Mar ID.csv)
3. Load processed file into PowerBI dashboard for data visualisation
